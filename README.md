# PF1 香蕉工具箱（pf1-banana）

Foundry VTT v13 · Pathfinder 1e 用的中文工具，三样东西：

## 资料浏览器

按 PF2 合集包浏览器的样子做的，分五页：**法术 / 专长 / 特性 / 物品 / 怪物与 NPC**（约 1.9 万条，资料来自开拓者1版中文维基）。

- **筛选**：左边每一组点一下＝包含（✓），再点＝排除（✗），再点＝不管。描述符、成分、类型这类一条有多个值的，可以切换「任一 / 全部」。
  - 法术：职业 + 环级（选了职业就按该职业的环级）、学派、子学派、描述符、施法时间、成分、豁免、法术抗力、领域、来源。
  - 专长：类型、先决条件（无 / 包含某字）、先决专长、PFS、来源。
  - 特性：类型、先决条件、PFS、来源。
  - 物品：分类、子类、部位、价格区间、施法者等级区间、灵光学派和强度、神器、来源。
  - 怪物与 NPC：CR 区间、类型、子类型、体型、阵营、地形、移动方式、HP / AC 区间、NPC 职业和种族、来源。
- **搜索**：中文、英文、拼音全拼（huoqiushu）、拼音首字母（hqs）。
- **详情**：维基条目全文，里面的链接可以跳到别的条目（浏览器里没有的打开维基页面）；可以发到聊天。
- **拖进角色卡**：按英文名和 PF1 / pf-content 合集包对上的条目可以直接拖（+2 防护戒指、标志性技能（唬骗）这类变体各占一行）；怪物页的条目可以拖进场景（需要 pf1-zh-monsters）。
- **打开方式**：快捷键 **B**（开 / 关，可在「配置控制」里改）；合集包侧栏顶上的「资料浏览器」按钮；角色卡上打开 PF1 自带浏览器时也会换成这个（可在设置里关掉）；宏：`game.modules.get("pf1-banana").api.open("spells", "火球")`。
- 怪物页默认只有 GM 能看，可以在模组设置里打开给玩家。

## 设置（都在模组设置里）

- 玩家可以看怪物 / NPC 页（默认关）、资料浏览器里可以购买（默认关）、角色卡上可以出售（默认关）、出售比例、替换 PF1 自带的浏览器。
- **资料浏览器内容**（设置里的按钮）：
  - 合集包：每个分页从哪些合集包取条目（能拖、能买的就是这些）。玩家另外受 Foundry 合集包权限限制，玩家看不到的合集包，对玩家来说等于没勾。
  - 来源书限制：只给玩家看勾选的来源书里的条目（比如只开核心规则书）。可以选应用到哪些分页、来源不明的合集包条目给不给看、GM 是否也受限。

## 一键购买

资料浏览器里物品和法术行尾的购物车（或详情里的「购买」）。默认关闭，在模组设置里打开：

- 物品按合集包书价；法术做成**卷轴 / 药水 / 魔杖**，选职业环级、可以调高施法者等级，价格用 PF1 自己的公式（含昂贵材料）。药水限 3 环以下、魔杖限 4 环以下。
- 对话框里选买家（自己的角色；GM 可以替任何玩家角色买）、数量，钱不够时按钮是灰的，点「确认购买」才扣钱。小面额不够会拆大面额找零。
- 每笔都密语给 GM 和买家。在地城里可以随时关掉。

## 快捷出售

角色卡物品栏（默认关闭，在模组设置里打开）：

- 每件物品的操作栏多一个金币按钮：选数量，「确认出售」。
- 货币栏下面「出售物品」：勾选要卖的（全选 / 只选没装备的 / 只选财宝），合计实时算，「确认出售」。
- 价格用 PF1 自己的算法：普通物品按「出售比例」设置（默认半价），财宝和贸易品全价，带次数的按剩余次数，未鉴定物品按玩家看到的价格。钱加进角色的普通货币（Item Piles 商店也认），结果密语给 GM 和卖家。

## 需要

- Foundry VTT v13，Pathfinder 1e 系统 11.x。
- 建议：**pf1e_compendium_chn**（合集包中文名，需要 Babele）、**pf-content**（更多可拖的条目）、**pf1-zh-monsters**（怪物可拖进场景）。都没装也能浏览全部资料。

## 安装

在 Foundry 的「附加模组 → 安装模组」底部填清单地址：

```
https://github.com/bananaeat/pf1-banana/releases/latest/download/module.json
```

或者从 Release 下载 zip，解压到 `Data/modules/pf1-banana/`，重启 Foundry，在世界里启用。

## 更新资料

资料是维基导出的快照。重新生成：`python tools/build_data.py <pf1-zh-wiki-data 目录>`，输出到 `data/`。
